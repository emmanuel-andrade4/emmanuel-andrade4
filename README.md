## 📌 Projetos em destaque
 
### 💄 Shop Beauty — Site para loja local de Varginha
**`Projeto Extensionista proposto pela faculdade`** ✅ **CONCLUÍDO**
 
Plataforma web de e-commerce para a loja Shop Beauty, com catálogo de produtos, autenticação de clientes e integração com backend em Node.js + Supabase.
 
**Funcionalidades:**
- Banner rotativo na página inicial
- Catálogo de produtos com filtros e busca por nome
- Barra de pesquisa com sugestões
- Cadastro e login de clientes, com sessão persistida via token
- Criação de pedidos com link automático para WhatsApp
- Páginas institucionais: contato, quem somos, política de privacidade e trocas/devoluções
- Acessibilidade com VLibras
**Stack:**
- Frontend: HTML5, CSS3, JavaScript
- Backend: Node.js + Express + Supabase
- Banco de dados: Supabase (858 produtos reais cadastrados — perfumes, maquiagens e produtos para hidratação dos cabelos)
🔗 Repositório: [github.com/RedellenJ/Site_Shop_Beauty](https://github.com/RedellenJ/Site_Shop_Beauty)
🌐 Deploy: [shopbeautyvga.netlify.app](https://shopbeautyvga.netlify.app)

### 🏡 Pousada Pé da Serra — Site institucional
✅ **CONCLUÍDO**
 
Site institucional para a Pousada Pé da Serra, com apresentação de suítes, galeria de imagens, informações de contato e reservas via WhatsApp.
 
**Funcionalidades:**
- Listagem dinâmica das suítes com cards renderizados em PHP
- Link de reserva por suíte com mensagem personalizada no WhatsApp
- Botão flutuante de WhatsApp para atendimento rápido
- Galeria de imagens com modal (fechamento por clique externo ou tecla ESC)
- Seção de contato com telefone, Instagram, endereço e horários
- Mapa incorporado com a localização da pousada
**Stack:**
- Frontend: HTML5, CSS3, JavaScript
- Backend: PHP (orientado a objetos — classes para pousada, quartos e contato)
🔗 Repositório: [github.com/RedellenJ/Site_Pousada_Pe_da_Serra](https://github.com/RedellenJ/Site_Pousada_Pe_da_Serra)
